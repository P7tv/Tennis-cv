# คู่มือทำเฉลย Keyframe — สำหรับทีม Loeuf

ใช้เวลาประมาณ **1 นาทีต่อคลิป** · ไม่ต้องติดตั้งโปรแกรมใด ๆ

## เริ่มต้น (ครั้งเดียว)

1. เปิดไฟล์ `labeling_tool.html` ด้วย **Chrome** (ดับเบิลคลิกได้เลย ทำงาน offline)
2. กรอกชื่อผู้ label, fps ของคลิป (30 หรือ 60), มือถนัดของผู้เล่น
3. กดปุ่มเลือกโฟลเดอร์ → เลือกโฟลเดอร์คลิปทั้งชุด (FH/BH/SV/...)
   — เครื่องมืออ่าน stroke type จากชื่อโฟลเดอร์ให้อัตโนมัติ

## ต่อคลิป (ขั้นต่ำแค่ 2 จุด)

1. เลื่อนหาเฟรมด้วย <kbd>←</kbd> <kbd>→</kbd> (ทีละเฟรม) หรือ <kbd>Shift</kbd>+ลูกศร (ทีละ 10)
2. หยุดที่จังหวะ**ลูกโดนแร็กเก็ต** → กด <kbd>I</kbd> (Impact) ⭐ บังคับ
3. หยุดที่จุดที่**มือ/แร็กเก็ตง้างไปหลังสุด** ก่อนเหวี่ยงกลับ → กด <kbd>B</kbd> (Backswing) ⭐ บังคับ
4. กด <kbd>Enter</kbd> → บันทึกและเปิดคลิปถัดไปเอง

เสร็จครบทุกคลิป → กด **Export CSV** ส่งไฟล์เดียวกลับมา

## กติกาสำคัญ 4 ข้อ

1. **Impact อยู่ระหว่าง 2 เฟรม** (ที่ 30fps เจอบ่อย) → เลือก**เฟรมหลัง**เสมอ แล้วกด <kbd>A</kbd> (ก้ำกึ่ง)
2. **คลิปเสีย** (มืด/เบลอหนัก/ตัดกลางสวิง) → กด <kbd>X</kbd> เลือกสาเหตุ แล้ว Enter ข้ามได้เลย — อย่าฝืนเดา
3. **ผู้เล่นไม่กลับท่าเตรียม** (เดินไปเก็บลูก) → กด <kbd>N</kbd> — นี่คือข้อมูลปกติ ไม่ใช่ความผิดพลาด
4. งานค้างได้ — เครื่องมือจำ progress ไว้ในเบราว์เซอร์ ปิดแล้วเปิดใหม่ทำต่อได้ (เครื่องเดิม + เบราว์เซอร์เดิม)

## จุดอื่น ๆ (ไม่บังคับ — เฉพาะคลิปที่ทีมเราขอเพิ่ม)

<kbd>U</kbd> Unit turn (ไหล่เริ่มหมุน) · <kbd>F</kbd> Follow-through สูงสุด · <kbd>R</kbd> กลับท่าเตรียมแล้ว
